# Slide 3 — Estructura metodológica / Objetivos

**Objetivo general**: aplicativo móvil/web + base de datos desplegada para gestionar, controlar e identificar automáticamente el inventario del FabLab usando DataMatrix.

**Objetivos específicos** (léelos como pasos secuenciales del proyecto, no como lista plana):
1. Diseñar y desplegar arquitectura de datos en la nube — migrar de Excel a BD relacional.
2. Desarrollar el módulo móvil/web con lectura y generación de DataMatrix para stock en tiempo real.
3. Implementar gestión espacial: administración de salas, traslados y registro histórico de movimientos.

Si preguntan "¿por qué esos 3 objetivos?": son las 3 capas del sistema — datos (infra), identificación (DataMatrix), y trazabilidad (movimientos entre salas). Cada uno mapea a un objetivo específico.
